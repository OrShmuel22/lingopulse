This directory contains the LingoPulse benchmark harness. `scenarios.json` is the ground-truth test corpus (25 realistic scenarios covering refine, dictionary, undo, and capture_style) and is tracked in git. Run output files (`run-*.json`) are gitignored and produced locally by `python -m lingopulse.benchmark run`; use `python -m lingopulse.benchmark compare` to diff two runs and `python -m lingopulse.benchmark list` to see history.
